## 1. PURPOSE

This document provides the framework for assessing whether Hidden
History may rely on legitimate interests as a lawful basis for specific
processing activities.

A legitimate-interest assessment should be completed before relying on
legitimate interests for a particular processing activity.

## 2. IMPORTANT

Legitimate interests must not be assumed merely because processing is
useful to Hidden History.

Each processing activity must be assessed separately.
